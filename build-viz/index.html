從原始檔到可燒錄的 BIOS ROM

你的 INF / DSC / FDF 如何變成 BIOS ROM

你寫下一個 .inf、.dsc 或 .fdf，build.exe 會呼叫一系列程式對它進行解析、編譯、組裝，最後產生可燒錄的 .fd（BIOS ROM）。點選下方任一檔案類型，追蹤它的完整旅程。

.inf Module

模組描述檔 (.inf)

定義模組的來源檔、相依套件、Library Classes、PCD 與模組類型。每個 UEFI 模組（Driver/Library/Application）都有一個 INF。

.dsc Platform

平台描述檔 (.dsc)

定義整個平台要建置哪些模組、Library Class 的對應關係、PCD 值與建置選項。是 build.exe 的主要入口（-p 參數）。

.fdf Flash Layout

映像佈局檔 (.fdf)

定義最終 BIOS ROM 的 Flash 佈局：哪些模組放進哪個 FV、FD 各區段大小與位置、Capsule 組成規則。

這些參數對應管線的哪裡

                
    
                    
  • -p 指定 DSC → 觸發 DscParser，決定要建置的所有模組與 Library 對應。
    • 
                    
  • -a/-b/-t 決定架構/目標/工具鏈 → 影響 tools_def.txt 中 CC/Linker 的選擇。
    • 
                    
  • -f 覆寫 FDF 路徑 → 影響 FdfParser 讀取的檔案，進而改變 GenFds 的組裝方式。
    • 
                    
  • -m 進入單模組建置，跳過其他 [Components]，只執行該 INF 的完整路徑。
